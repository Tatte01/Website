🎮 Dungeon Bound

Technology: C++ SFML

About the Project

A simple C++ game where the goal is to complete it as fast as possible. Control the white cube and jump up platforms to reach the goal — a black square.

Key Features:

  • The pink square is an enemy that resets the game on collision
  • Gold coins reduce your total time by a few seconds
  • The Score Board shows the top 10 fastest times from a text file

Made during a 10-week course as the final project, built in Microsoft Visual Studio 2022 using C++ and SFML for graphics.

🔌 Bad USB

Technology: Python PowerShell

About the Project

A USB that automatically installs all preferred programs on a new computer. Despite the name, this was built with a legitimate purpose — automating a personal setup routine.

How it works:

  • A small Python HID program opens a PowerShell terminal
  • PowerShell executes a .ps1 file that installs everything
  • Built this way to learn how to use HID with Python

🎬 Jellyfin Media Server

Technology: Bash

About the Project

A self-hosted media server built on a Raspberry Pi 5, running Jellyfin as a free and open-source alternative to Netflix. Streams movies and TV shows to any device at home or remotely using Tailscale as a secure private tunnel.

Setup highlights:

  • 2TB external drive mounted to the Pi for media storage
  • Wireless file transfer from any Windows PC via Samba network share
  • Full setup documented in a public HTML guide

🐾 CavaCavat

Technology: React Firebase Vite GitHub Pages

About the Project

Designed and developed a full-stack web application for a Cavalier King Charles Spaniel kennel in southern Sweden. Features a public-facing website with dog family trees, a blog, and a photo gallery, alongside a secure admin panel for content management.

Key Contributions:
  • Implemented Firebase Authentication for secure single-admin access
  • Designed a NoSQL data model in Firestore for dog lineage tracking
  • Built reusable React components with responsive design across desktop, tablet and mobile
  • Managed secure environment variables and deployment pipeline via GitHub Pages
  • Maintained technical documentation throughout development using LaTeX in Overleaf
