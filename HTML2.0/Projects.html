About the Project

This game is a simple C++ game that the goal is to complete,the game as fast as possible.
In the game when you get in you can control the white cube and ment to jump up the platforms to reach the goal that is the black square.
The pink square is an enemy that resets the game if you collide with it.
The gold coins is time savers that reduces the total time at the end by a few secounds.
In the menu of the game you can click Score Board as you see in the first picture.
The Score Board shows from a text file the top 10 fastest times the game as been completed.

This game was made in a Course that was 10 weeks long and this was the End projekt and was made in Microsoft visual studio 2022 using C++ as the codeing language and SFML to make the graphics. itch.io

This is called a Bad USB online somewhat, but it's more about what you do with it.
You can make it do bad things, but I wanted to make a USB that installs all programs that I want on a new computer.

It's definitely possible to make in other ways, but I wanted to learn how to use HID with Python.

PI 5 Jellyfin Media Server

Finished March 2026

Bash

🎬 Jellyfin Media Server

Technology: Bash

About the Project

A self-hosted media server built on a Raspberry Pi 5, running Jellyfin Media Server as a free and open source alternative to services like Netflix. The server streams movies and TV shows to any device at home or remotely anywhere in the world using Tailscale as a secure private tunnel. Media is stored on a 2TB external drive mounted to the Pi, and can be transferred wirelessly from any Windows PC using a Samba network share. The entire setup process is documented in a public HTML guide covering every step and command used.
And you can read that guide here: Jellyfin Server Guide
